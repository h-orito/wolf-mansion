# 05. E2E

## 方針

- **`e2e/` 配下**に実装する
- **Playwright** を使用
- パッケージマネージャは **pnpm**
- **ローカルでの動作確認専用**。CI では実行しない (走らせる前提で設計しない)
- 機能の細かい調査により e2e テストケースも設計し、細かくレビューしていく
  - frontend の画面ごとの調査結果と連動して、必要なテストケースを洗い出す
  - 画面ごとの詳細は `doc/migration/screens/<screen>.md` に集約し、そこから対応ケースを引く
  - **時系列の happy-path** (村作成→参加→開始→進行→終了) は `doc/migration/scenarios/<scenario>.md` に authoring し、各シナリオ md ≒ 1 つの `test.describe` の土台とする ([scenarios/README.md](scenarios/README.md))

## 実行環境

### DB
- **ローカル開発環境の DB とあいのり**で良い (専用 DB やリセット手順を作り込まない)
- 既存実装 (`http://localhost:8091/wolf-mansion/`) も同じローカル DB を共有しているため、e2e の結果が既存画面側にも見える / 逆も成立
- テスト用ユーザーは既存の `local_test_credentials.md` のものを利用 (ローカル DB の全プレイヤーは password `testuser`)

### Port / 起動 (確定)

- **Playwright の `webServer` 機能で backend / frontend を自動起動**する
- 通常起動と **別ポート**を使い、開発サーバーを止めずに e2e を回せるようにする
  - 例: 通常 backend 8089 / frontend 5173 → e2e 時 backend 18089 / frontend 15173
  - 具体的なポート番号は Step 0 (or e2e セットアップ step) で確定
- `playwright.config.ts` の `webServer` に backend (`./gradlew bootRun --args=--server.port=18089`) と frontend (`pnpm dev --port 15173`) を登録、baseURL も対応するポートに合わせる
- e2e 専用 Spring profile (`e2e` 等) を用意して、必要なら local 設定を上書き

### スクリーンショット
- 保存先は **`e2e/` 配下の専用ディレクトリ** (例: `e2e/test-results/` `e2e/playwright-report/` 等、Playwright デフォルト)
- **`.gitignore` に追加**して git 管理外にする
- (参考) Claude Code の playwright MCP から撮るスクショは引き続き `.playwright-mcp/` に置く運用 (既存ルール踏襲)

### Daychange (確定)

- バックエンドに **「日付を更新する」デバッグ機能**が存在するため、これを叩いて村の日付進行を制御する
- **Step 0 で現行エンドポイントの URL / 権限 / 認証方法を調査**し、REST 化後も **同等の endpoint を残す**
- 時刻操作や専用エンドポイントの新設は基本不要

### テスト間の DB 状態 (確定)

- **DB はあいのり前提**で、リセット (mysqldump 等) はしない
- **各テストが setup/teardown で独立データを作る**規約とする
  - 各テストは自分用の村 / 参加者を作成し、`afterEach` で削除 or 廃村
  - 他テストと被らない名前 (`{testName}-{timestamp}` 等) を使う
- これにより **並列実行可能** (Playwright のデフォルト並列モードを活かせる)
- どうしても順序依存が必要な一連の流れは `test.describe.serial` で明示

### 失敗時の artifacts (確定)

- **on-failure**: 失敗時のみ trace + screenshot を保存。video は取らない
  - `use: { trace: 'on-first-retry', screenshot: 'only-on-failure', video: 'off' }` 相当
- 保存先は Playwright デフォルトの `e2e/test-results/` および `e2e/playwright-report/`
- `.gitignore` に追加して git 管理外

## 想定するスコープ

- 認証 (ログイン / ログアウト / refresh)
- 主要画面の表示確認 (smoke)
- 村のライフサイクル (Prologue → Progress → Epilogue → Finished, 廃村) — 時系列 happy-path は [scenarios/](scenarios/README.md) 配下に分けて記録
- 発言種別の出し分け、表情差分、装飾タグ、アンカー、秘話、返信 等
- 投票 / 能力 / コミット
- 認可マスク (足音、死亡理由など)
- creator / admin 操作 (kick, 廃村, 強制退村, etc.)
- **外部公開済み API の挙動ピン留め** ([02-backend.md](02-backend.md) 参照)
